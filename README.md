# nazoya｜謎解き・暗号メーカー

文章を暗号化／復号できる静的Webツールです。

| 項目 | 内容 |
|---|---|
| バージョン | 1.0.0 |
| 状態 | 公開中 |
| 稼働先 | Vercel（Web版）／ Windows アプリは GitHub Releases |
| 実装 | HTML / CSS / JavaScript（素の、外部リソース不使用）＋ Windows 版（.NET 8 / WinForms） |
| 更新履歴 | [CHANGELOG.md](CHANGELOG.md) |

## 📖 概要

暗号文を「問題カード」画像にしてダウンロードできるので、謎解きイベントやクイズの問題づくりに使えます。入力した文章はブラウザの中だけで処理され、外部に送信されません。

## ✨ 機能

### 暗号ツール（4方式）
- **シーザー暗号**：五十音・カタカナ・英字・数字を、指定した「ずらし幅」だけずらします。同じ幅で復号できます。
- **文字反転**：文章を逆順に並べ替えます（暗号化と復号は同じ操作）。
- **あ↔数字変換**：あ=01、い=02、う=03…ん=46 と、五十音順の番号に変換します。カタカナ入力にも対応。復号時はスペース区切りの2桁数字（または数字の塊を2桁ずつ）として読み取ります。
- **モールス信号（日本語カナ）**：カナ対応表による和文モールス変換。ひらがな入力はカタカナとして扱い、濁点・半濁点は「゛」「゜」の符号を後ろに付けて表します。空白は「/」で区切ります。

どの方式も「暗号化する」「復号する」の両方向に対応し、結果のコピー、入力と出力の入れ替えができます。

### 問題カード
- 「元の文章」を現在の方式で暗号化した文だけを載せたカード画像（1200×630 PNG）を Canvas で描画し、ダウンロードできます。
- カードには問題文・方式名・任意のヒント欄が入ります。**答え（元の文章）はカードに含まれません。**
- 問題文がカードの上限（7行）を超える場合は、切り捨てずにメッセージを表示して生成を止めます。
- 画面上にプレビューが表示されます。

### その他
- 使い方と各方式の説明セクション付き。
- PWA対応（ホーム画面に追加可能、オフラインでも動作）。
- テーマはダーク／ライトの手動切り替え（既定はダーク、選択は端末に保存されます）。

## 📝 使い方

1. 「元の文章」に文章を入力します。
2. 方式を選び（シーザー暗号ならずらし幅も指定）、「暗号化する」を押します。
3. 復号するときは、暗号文を入力して同じ方式で「復号する」を押します。
4. 問題カードは、ヒント（任意）を入れて「カードを生成してダウンロード」を押します。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。4方式の変換（シーザー暗号／文字反転／あ↔数字変換／モールス信号）・符号表・濁点の扱いは Web 版と同一で、問題カード（1200×630 PNG）の保存もできます。オフラインで使えます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Nazoya.exe` を生成

## 📋 技術メモ

- ビルド不要の静的サイト（素の HTML / CSS / JavaScript、外部リソース不使用）。変換ロジックは DOM 非依存の `js/cipher-core.js` に分離してあり、`npm test`（node:test、依存なし）で単体テストが動きます。
- モールス符号は内部で `.` / `-` として処理し、表示時に `・` / `−` へ変換しています。符号表は標準の和文モールス（無線局運用規則・別表第1号）に準拠しています。濁点は `..` の符号を直前のカナの後ろに付けて表し、復号では直前の文字と組み合わせて濁音に戻します。
- Service Worker（`sw.js`）が同一オリジンのGETリクエストを `nazoya-v1` キャッシュに保存します。
- テーマの保存キー（localStorage）は `nazoya-theme` です。
- アイコンは PIL で生成した PNG（角丸の indigo 背景に白い「謎」の文字）です。
